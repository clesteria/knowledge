= sshd設定

いつもお決まりの設定をするが、その効果を逐一覚えてないのでメモ。

== /etc/sshd/sshd_config.d 配下に置く意味

大昔から /etc/sshd_config を編集する、という慣習を継承していたが、実際には /etc/sshd/sshd_config.d 配下に明示的に設定したい項目だけ抜き出して置いておくのが想定された使い方だったため、それに倣うようにした。

若い頃の慣習が先に頭に入っているので、こうして書いておかないと、それすらどうしてだっけか、となりがちのため、この程度も書き残しておく。

=== 設定内容

`PermitRootLogin no`::
rootユーザのログインを無効。有効にする理由がまったくないため。
`PasswordAuthentication no`::
パスワード認証を無効。鍵認証のみを有効にするため。
`PermitEmptyPasswords no`::
空パスワードを無効。パスワード認証を使用しないのであまり意味はないが、有効にする理由もないため。
`ChallengeResponseAuthentication no`::
チャレンジ/レスポンス認証を無効。パスワード認証の補助機能みたいなものだが、パスワード認証を使用しないので、これも同様。
`KbdInteractiveAuthentication no`::
キーボードインタラクティブ認証を無効。使ったことがないのでよく分かってないが、鍵認証には不要なので。
